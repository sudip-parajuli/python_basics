# Python Fundamentals Practice

My early Python exercises, organized by topic. This repository records the
foundations I practiced before building larger Django, automation and AI projects.
Each file is a standalone exercise rather than part of a packaged application.

## Topics

| Folder | Practice |
| --- | --- |
| `variables/`, `data_types/`, `operators/` | Values, types, expressions and variable swapping |
| `conditional_statements/`, `loop/` | Branching, grading, arithmetic and iteration |
| `list/`, `tuples/`, `sets/`, `dictionary/` | Collections and their operations |
| `functions/`, `lambda/` | Reusable functions and anonymous functions |
| `factorial/`, `fibonacci_series/` | Iterative and recursive solutions |
| `OOP/` | Classes, inheritance and method resolution order |

## Run an exercise

Install Python 3, clone the repository and run a file from its root:

```sh
git clone https://github.com/sudip-parajuli/python_basics.git
cd python_basics
python factorial/factorial_using_recursion.py
python OOP/mro.py
```

Some exercises request console input. Read the selected file to see its inputs,
example values and output. These exercises do not require a web server or database.

## How to use this repository

Change an example input, predict its output and compare the iterative/recursive
versions. The scripts are learning notes; edge-case coverage and automated tests
are not comprehensive.

For a later API project with setup instructions and regression tests, see my
[Django REST Framework internship practice](https://github.com/sudip-parajuli/drftutorial).
